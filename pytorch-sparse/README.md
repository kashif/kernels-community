## pytorch-sparse

Sparse matrix kernels from
[pytorch_sparse](https://github.com/rusty1s/pytorch_sparse) by Matthias Fey.

Copyright (c) 2020 Matthias Fey. Licensed under the MIT license.

The kernel sources are taken from upstream; the operator registration is
adapted so that the namespace is generated by `kernel-builder` instead of
being hardcoded to `torch_sparse::`.

Built for `cpu`, `cuda` and `rocm`. The ROCm variant compiles the same CUDA
sources via hipify. It carries two ROCm fixes that upstream has not released
yet: a 64-bit warp shuffle mask (required from ROCm 6.4.3 on), and an explicit
shuffle width of 32, without which the `spmm` broadcast reads the wrong row on
64-wide wavefronts.

## Usage

```python
import torch
from kernels import get_kernel

pytorch_sparse = get_kernel("kernels-community/pytorch-sparse")

rowptr = torch.tensor([0, 2, 4, 6], device="cuda")
col = torch.tensor([0, 1, 1, 2, 0, 2], device="cuda")
value = torch.randn(6, device="cuda")
mat = torch.randn(3, 64, device="cuda")

out = pytorch_sparse.spmm_sum(None, rowptr, col, value, None, None, mat)
```

## Exported operators

| Operator | Backends |
| --- | --- |
| `spmm_sum`, `spmm_mean`, `spmm_min`, `spmm_max` | cpu, cuda, rocm |
| `ind2ptr`, `ptr2ind` | cpu, cuda, rocm |
| `non_diag_mask` | cpu, cuda, rocm |
| `random_walk` | cpu, cuda, rocm |
| `relabel`, `relabel_one_hop` | cpu |
| `saint_subgraph`, `sample_adj`, `ego_k_hop_sample_adj` | cpu |

## Notes on scope

Only the compute kernels and their operator wrappers are packaged. The
Python layer that upstream builds on top of them — `SparseTensor`, `storage`,
and the tensor-manipulation helpers — is not included; it belongs in the
calling library.

Three groups of upstream operators are deliberately left out:

- **METIS partitioning** (`partition`, `partition2`, `mt_partition`) needs an
  external METIS build, which would make this kernel non-self-contained.
- **Heterogeneous neighbour sampling** (`hetero_neighbor_sample`,
  `hetero_temporal_neighbor_sample`, `hgt_sample`) takes and returns
  `Dict[str, Tensor]`, and is CPU-only graph sampling rather than a kernel.
- **`neighbor_sample`** depends on `parallel-hashmap`, which would have to be
  vendored. Sampling is covered by `pyg-lib` these days.
